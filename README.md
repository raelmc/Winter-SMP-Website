# Winter SMP Website

Die Website zum Minecraft-Server Winter SMP. Hier findest du den Countdown zum Serverstart, Infos zum Beitritt, die Serverregeln, den Zeitplan und das Team.

## Was du auf der Website findest

- **Home:** Winterliches Startdesign mit fallendem Schnee und Countdown zum Serverstart
- **Info & Join:** Serverinfos und Hinweise zum Beitritt
- **Rules:** Die Regeln für den Server
- **Progression:** Die drei Meilensteine „Server Start“, „Diamond Stufe“ und „End Kampf“
- **Team:** Rael und Leo

## Lokal starten

Die Website besteht aus HTML, CSS und JavaScript. Es ist kein Build-Schritt nötig. Öffne `index.html` im Browser oder starte die Website in VS Code mit der Erweiterung „Live Server“.

## Projektstruktur

| Datei oder Ordner | Inhalt |
| --- | --- |
| `index.html` | Aufbau und Inhalte der Website |
| `styles.css` | Design und Layout |
| `script.js` | Countdown und interaktive Funktionen |
| `site-config.js` | Einstellungen der Website |
| `assets/` | Logo und weitere Grafiken |
